# Meu Controle — publicação GitHub Pages

Este pacote contém somente o aplicativo **sem dados financeiros pessoais**.

## Publicar no GitHub Pages (grátis)

1. Crie um repositório **público** chamado `meu-controle` no GitHub.
2. Abra o repositório e selecione **Add file > Upload files**.
3. Extraia o ZIP no computador e envie **os arquivos de dentro da pasta**, não o ZIP.
4. Faça **Commit changes**.
5. Abra **Settings > Pages**.
6. Em **Build and deployment > Source**, selecione **Deploy from a branch**.
7. Selecione `main` e `/(root)` e clique **Save**.
8. Aguarde a publicação; a URL costuma ser `https://SEU-USUARIO.github.io/meu-controle/`.
9. No iPhone, abra a URL no Safari > Compartilhar > Adicionar à Tela de Início > Abrir como App > Adicionar.
10. Abra o ícone instalado, toque em **Importar meus dados** e selecione o arquivo JSON privado guardado no app Arquivos do iPhone.

## Privacidade

**NÃO envie ao GitHub** o arquivo `MEUS_DADOS_PRIVADO_NAO_ENVIAR_GITHUB.json`, nem backups exportados, planilhas, capturas de tela de dados ou o ZIP antigo que inclui receitas/despesas no HTML.

O site do GitHub Pages é público; esta versão não inclui seus dados. Os registros importados ficam no armazenamento local do dispositivo e **não sincronizam automaticamente** entre computador e iPhone. Exporte backups periodicamente em Ajustes e guarde-os em local seguro. O aplicativo não tem login nem criptografia adicional dos dados locais.
